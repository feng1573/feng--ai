# lead-agent · 外贸获客 Agent（开源项目）

> 状态：🚧 骨架已建，待方法论访谈 | 目标：免费开源在 GitHub

一个行业专注的外贸获客 AI Agent：输入**产品类目 + 目标市场**，输出完整获客工作包——
客户画像 → 线索渠道调研 → 潜在买家清单 → 多语种开发信草稿 → 跟进节奏建议。

核心资产不是代码，是**被文字化的外贸获客手艺**（skill）。代码只是把手艺装进容器。

## 目录规划

```
lead-agent/
├── README.md
├── LICENSE              # 开源许可证（待定：MIT / Apache-2.0）
├── skills/
│   └── lead-hunter/     # 主 skill：获客方法论操作手册
│       ├── SKILL.md     # 流程：画像→渠道→线索→触达→跟进
│       └── references/  # 品类/市场知识库（海关数据口径、展会名录等）
├── templates/           # 开发信模板（分语种、分场景首触/跟进/破冰）
├── tools/               # 辅助脚本（CSV 整理、批量渲染模板等）
└── docs/
    ├── methodology.md   # 方法论长文（README 的灵魂）
    └── install.md       # 如何在 DSH / Claude Code 等环境安装使用
```

## 合规设计原则（不可妥协）

- ❌ 不做自动群发、不做违反平台 ToS 的批量抓取、不碰个人数据黑产
- ✅ 只做：公开商业信息聚合调研 + 内容生成 + 流程编排，发送动作由人执行
- ✅ 每条线索标注来源与获取方式，可复核
