# finance-studio · 财经自媒体内容生产线

> 状态：🚧 骨架已建，待定义分析框架 | 负责人：feng1573 + DSH agent

用 AI 把「宏观事件」加工成「普通人听得懂、用得上的经济知识与建议」。
知识来源四条线：**国际政治 · 金融 · 地缘关系 · 国内经济制度**。
分发平台：**抖音 / 视频号（短视频）· 小红书（图文）· 公众号（长文）**。

## 目录规划

```
finance-studio/
├── README.md            # 本文件
├── framework/           # 分析框架（skill 化之前的原始文档）
│   └── macro-lens.md    # 四线拆解模型：事件→逻辑链→与普通人关联→行动边界
├── skills/              # 沉淀出的自定义 skill（最终形态）
│   └── macro-content-studio/   # 主生产 skill
├── topics/              # 选题库（每个选题一个 md 文件）
├── drafts/              # 生成中的稿子（按 平台/日期 组织）
└── published/           # 已发布终稿存档
```

## 工作流（目标形态）

1. **喂事件**：一句热点新闻或话题（例：「美联储降息 25bp」）
2. **拆逻辑**：按 macro-lens 四线各问一遍，找出与普通人的利益关联点
3. **出初稿**：一鱼多吃——同一内核改写成四种体裁
4. **人工终审**：博主本人把关观点与表达，AI 不代持立场

## 内容红线（写进每个 skill）

- 只做经济知识与逻辑普及，**不给个股买卖建议、不做个性化理财推荐**
- 引用数据必须带来源和日期；政策类数字标注截至时间
- 争议性判断要呈现反方观点，不装确定性
